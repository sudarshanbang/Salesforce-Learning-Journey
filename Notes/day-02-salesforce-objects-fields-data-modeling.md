## Standard Objects
- Account
- Contact
- Lead
- Opportunity
- Case

## Custom Objects
Custom objects are created for business requirements.
API names end with `__c`.

Examples:
- Student__c
- Expense__c

## Records
A record is one row inside an object.

## Fields
Fields store information about a record.

Common field types:
- Text
- Number
- Currency
- Date
- Date/Time
- Checkbox
- Picklist
- Long Text Area
- Email
- Phone
- URL
- Formula

## Object Manager
Used to create and manage objects, fields, page layouts, validation rules and relationships.

## Schema Builder
Visual tool for viewing objects, fields and relationships.

## Best Practices
- Use meaningful names.
- Select correct field types.
- Design the data model before automation.
