## What is a Screen Flow?
A Screen Flow is an interactive Flow that collects input from users through one or more screens.

## Screen Components
- Text
- Number
- Date
- Checkbox
- Picklist
- Radio Buttons
- File Upload
- Display Text

## Variables
Store user input during Flow execution.

Types:
- Text
- Number
- Boolean
- Date
- Record
- Collection

## Choice Resources
Used to populate Picklists and Radio Buttons.

## Loop
Processes each record in a collection one at a time.

## Navigation
- Next
- Previous
- Finish
- Pause

## Best Practices
- Keep screens simple.
- Validate input.
- Use meaningful labels.
- Test every path.
