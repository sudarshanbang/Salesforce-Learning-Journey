## What is a Record-Triggered Flow?
A Flow that runs automatically when a record is created or updated.

## Before-Save Flow
Use for updating fields on the same record.
Faster than After-Save.

## After-Save Flow
Use for:
- Creating related records
- Sending emails
- Updating related records
- Calling actions

## Best Practices
- Use Before-Save for field updates.
- Use After-Save for related records.
- Test with Debug.
- Use meaningful element names.
