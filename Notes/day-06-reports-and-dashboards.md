## What is a Report?
A Report is a structured list of Salesforce records used for analysis.

## Report Types
- Standard Report Types
- Custom Report Types

## Types of Reports
### Tabular
Simple rows of records.

### Summary
Groups records by one field.

### Matrix
Groups by rows and columns.

### Joined
Multiple report blocks together.

## Filters
Used to limit displayed records.

## Grouping
Organizes records by a field.

## Charts
- Bar
- Column
- Line
- Pie
- Donut

## Dashboards
A Dashboard visually displays report data.

## Dashboard Components
- Chart
- Metric
- Gauge
- Table
- Funnel

## Dynamic Dashboard
Shows data based on the logged-in user.
